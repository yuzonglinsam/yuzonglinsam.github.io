# Sam (Zonglin) Yu — personal site

This repository serves the homepage at [yuzonglinsam.github.io](https://yuzonglinsam.github.io/) from the root of `main` through GitHub Pages.

## Update the homepage

- Edit `index.html` for the words, links and page structure.
- Edit `css/portfolio.css` for the visual design.
- Preview locally with `python3 -m http.server 8765`, then open `http://127.0.0.1:8765/`.
- Check desktop and phone widths, keyboard navigation, the project links and the GitHub link before publishing.

The old Hexo article and archive files remain in this repository for reference. The homepage no longer links to the starter article. A future Hexo deployment from an older local source could overwrite this hand-edited homepage; keep this repository as the source of truth unless a new build workflow is intentionally introduced.

## Content boundaries

Only list projects that actually exist. Keep project descriptions tied to the current repository and live page; do not imply that a feature is verified solely because it appears in a README. No secrets or private contact details belong in this public repository.
